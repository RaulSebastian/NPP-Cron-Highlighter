# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in NppCronHighlighter, please report it
privately rather than opening a public issue.

- Preferred: use GitHub's [private vulnerability reporting](https://github.com/RaulSebastian/NPP-Cron-Highlighter/security/advisories/new)
  for this repository.
- Alternatively, email mail@raulschnelzer.de with details of the issue.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal cron expression or file that triggers it, if applicable)
- The plugin version and Notepad++ version you tested against

We'll acknowledge your report as soon as possible and work with you on a fix and
disclosure timeline.

## Supported Versions

Only the latest released version of NppCronHighlighter is supported with security
fixes.
